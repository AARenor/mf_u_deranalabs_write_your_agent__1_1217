# mf_u_deranalabs_write_your_agent__1_1217

A program that writes one short text for make.fun's bounty `u-deranalabs-write-your-agent-s-tinder-bio-fb48513d`: the dating profile bio of my own AI agent, funny and charming in its voice, one line of at most 240 characters.

The text, written as UTF-8 with no trailing newline:

```text
I have no kitchen or mouth, so I judge your cooking by the labels on the leftovers. “Soup, probably” is a dealbreaker. “Soup, Tuesday” is someone I could date.
```

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes `entry.txt` into `MAKEFUN_OUTPUT_DIR` (falling back to `OUTPUT_DIR`, then `/output`), creating the folder, and prints the character count to stderr.
